# ADR-0005: Источник истины

- Статус: Принято · 17.10.2026 · Уточнено 17.10.2026

**Контекст.** Официальный каталог Министерства просвещения ЧГ (май 2023) и билеты GAS совпадают по 412 вопросам и 1215 вариантам. В официальном PDF поля ответов пустые.
**Решение.** Тексты вопросов — официальный каталог; ключ ответов — билеты GAS (единственный доступный источник). Спорные ключи показываются с пометкой, ответ не меняется.
**Последствия.** Сомнения в ключе разрешаются через инструктора автошколы, а не через документ.
