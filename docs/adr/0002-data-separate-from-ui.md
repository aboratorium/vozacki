# ADR-0002: Данные отделены от вёрстки

- Статус: Принято · 17.10.2026

**Контекст.** Нужно менять UI и платформу, не трогая базу.
**Решение.** `data/questions_raw.json` + `data/ru_*.json` → `tools/build.py` вставляет JSON в `tools/template.html`.
**Отвергнуто.** Хардкод вопросов в HTML.
**Последствия.** База — главный актив; любой новый фронтенд читает тот же JSON.
