# ADR-0003: Извлечение из PDF без OCR

- Статус: Принято · 17.10.2026

**Контекст.** PDF не сканированный: текст — слой, ответ — чёрный квадрат (векторная заливка), фото — встроенные растры.
**Решение.** PyMuPDF: текстовый слой + векторная разметка + встроенные изображения; таблички под знаками склеиваются со знаком.
**Отвергнуто.** OCR, сторонние сервисы распознавания.
**Последствия.** 0 ошибок распознавания; 415/415 вопросов с ровно одним ответом.
