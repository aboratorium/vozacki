# ADR-0001: Одна статическая страница без бэкенда

- Статус: Принято · 17.10.2026

**Контекст.** Один пользователь, ~400 вопросов, подготовка 2–4 недели.
**Решение.** Single-file app: HTML + встроенные данные и картинки, без сервера и фреймворков.
**Отвергнуто.** Next.js + сервер; нативное приложение.
**Последствия.** Деплой = одна публикация. Переезд на Next.js (v3) — перенос UI, база не меняется (см. ADR-0002).
