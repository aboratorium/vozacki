# ADR-0012: Интервальные повторения, перемешивание вариантов, флажки

- Статус: Принято · 18.10.2026 · Частично заменяет ADR-0007

**Контекст.** В v1.1 вопрос считался выученным после 2 верных ответов подряд и больше не возвращался; варианты A/B/C стояли в порядке PDF, позицию правильного ответа можно было запомнить вместо смысла.
**Решение.**
- Упрощённая система Лейтнера по дням: у вопроса «ящик» `box` 0–3 и дата `due`. Ошибка → `box = 0`, повтор сегодня. Верный ответ → `box + 1`, повтор через 1, 3, затем 7 дней (с начала суток).
- Режим «Повтор» = вопросы с `due` ≤ сейчас; режим «Учёба» = новые + невыученные с наступившим `due`.
- Порядок вариантов перемешивается при каждом показе во всех режимах.
- Флажок «сложный» (☆/★) на любом вопросе, отдельный режим «Сложные».
- Метрика «выучен» (2 верных подряд) сохранена для совместимости.
**Отвергнуто.** SM-2 / FSRS — точнее, но непрозрачны и избыточны для 2–4 недель подготовки к 412 вопросам.
**Последствия.** Записи v1.1 получают `box = min(streak, 3)` и `due` от последнего ответа при первом запуске; флажок и расписание входят в резервную копию.
