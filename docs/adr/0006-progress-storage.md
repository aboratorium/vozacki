# ADR-0006: Хранение прогресса

- Статус: Принято · 17.10.2026 · Пересмотрено 17.10.2026 (v1.1)

**Контекст.** Владелец занимается без сети; прогресс должен переживать перезапуски. На старте было две версии — онлайн-артефакт claude.ai (облачная синхронизация) и офлайн-PWA — с разным прогрессом.
**Решение.** Единственный продукт — офлайн-PWA. Прогресс в localStorage устройства; приложение просит браузер не удалять хранилище (`navigator.storage.persist()`); резервная копия — кнопка «Сохранить в файл» (Web Share / скачивание) и «Восстановить» со слиянием по времени ответа. Онлайн-артефакт больше не обновляется.
**Отвергнуто.** Свой бэкенд + БД; синхронизация через облако claude.ai (требует сети, вторая кодовая база).
**Последствия.** Одна сборка и один прогресс. Синхронизация между устройствами — только через файл копии; полноценная — v3 (аккаунты).
