# ADR-0006: Хранение прогресса

- Статус: Принято · 17.10.2026 · Уточнено 17.10.2026 (офлайн-приоритет)

**Контекст.** Владелец занимается без сети; прогресс должен переживать перезапуски.
**Решение.** Основное приложение — PWA: прогресс в localStorage на устройстве, офлайн через service worker. Онлайн-артефакт claude.ai дополнительно синхронизирует прогресс в облако (artifact db, приватный документ пользователя).
**Отвергнуто.** Свой бэкенд + БД.
**Последствия.** Прогресс PWA и артефакта не связан. Резервная копия в файл — кандидат P2 (см. COMPETITORS.md).
