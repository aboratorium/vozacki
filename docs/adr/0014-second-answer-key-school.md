# ADR-0014: Второй ключ ответов — автошкола

- Статус: Принято · 23.10.2026 · Дополняет ADR-0005

**Контекст.** 23.10.2026 автошкола владельца прислала `Testovi_bilingual_pages_01-57.pdf` — машинный перевод (Google) официального каталога на EN/RU с ответами, отмеченными ручкой. Это второй независимый ключ.
**Сверка.** Отметки сняты автоматически (векторные штрихи у квадратиков), вопросы сопоставлены с базой по русскому тексту, картинкам (perceptual hash) и номеру варианта; каждое расхождение проверено по изображению страницы.

| Показатель | Значение |
| --- | --- |
| Вопросы с вариантами, сравнено | 358: совпадает 346, расходится 12 |
| Вопросы на порядок проезда | 10: совпадает 10 |
| Без отметки у автошколы | 42 (в основном № 371–415, техника и первая помощь) |
| Не сопоставлено надёжно | 5 (№ 265, 269, 270, 312, 339) |

Расхождения: № 6, 81, 111, 148, 220, 221, 283, 300, 344, 356, 358, 386. В № 283, 300, 356, 358 ответ автошколы совпадает с ранее отмеченными сомнениями (Правилник / флаги).
**Решение.** Основной ключ в приложении не меняется (GAS). В 12 вопросах хранится поле `sch` — индекс варианта автошколы; после ответа показывается «Автошкола отмечает: …». Окончательный выбор — после ответа инструктора, затем ключ правится в `data/questions.json`.
**Последствия.** Проверка T7 в сборке: индекс `sch` должен существовать. Скрипты сверки — `tools/school/` не вынесены (разовая операция), методика описана здесь.
