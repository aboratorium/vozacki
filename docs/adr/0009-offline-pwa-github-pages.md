# ADR-0009: Офлайн-PWA на GitHub Pages

- Статус: Принято · 17.10.2026

**Контекст.** Артефакт claude.ai без сети не открывается; нужен ярлык на экране «Домой» iPhone.
**Решение.** PWA: Tailwind скомпилирован в статичный CSS, `sw.js` кэширует всё при первом запуске (cache-first, версия кэша = хэш сборки), иконка — знак «Главная дорога» с буквой B. Хостинг — GitHub Pages, репозиторий `aboratorium/vozacki`.
**Отвергнуто.** Netlify / Cloudflare Pages (лишний аккаунт); нативное приложение.
**Последствия.** Сайт публичный (вопросы — открытый государственный каталог). Обновление = push в `main`, приложение подтягивает его при запуске с сетью.
