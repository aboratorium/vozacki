# ADR-0013: Индикатор готовности

- Статус: Принято · 18.10.2026

**Контекст.** Нужен честный ответ на «я готов к экзамену?» вместо ощущения.
**Решение.** Уровень по последним 5 пробным экзаменам и доле выученных вопросов:

| Уровень | Условие |
| --- | --- |
| Мало данных | меньше 3 пробных экзаменов |
| Готов | сдано ≥ 4 из 5, средний балл ≥ 72 из 80, выучено ≥ 80% вопросов |
| Почти готов | сдано ≥ 3 из последних |
| Рано | иначе |

Показывается в шапке (нажатие открывает «Прогресс») и первой карточкой во вкладке «Прогресс» с расшифровкой.
**Отвергнуто.** Вероятностная модель сдачи — данных одного человека мало, а формула непрозрачна.
**Последствия.** Пороги — допущение (ADR-0008: баллы по типам не опубликованы); меняются тремя числами в `readiness()`.
