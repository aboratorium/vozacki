# ADR-0004: Перевод и подсказки готовятся заранее

- Статус: Принято · 17.10.2026

**Контекст.** Нужна работа офлайн, предсказуемость и нулевые затраты в работе.
**Решение.** Перевод, подсказки и флаги хранятся в `data/ru_*.json`.
**Отвергнуто.** Перевод через API на лету.
**Последствия.** Перевод проверяется до публикации; новый язык = новый файл `xx_*.json`.
