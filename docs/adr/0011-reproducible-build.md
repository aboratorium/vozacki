# ADR-0011: Воспроизводимая сборка одной командой

- Статус: Принято · 17.10.2026

**Контекст.** В v1.0 скрипты ссылались на временную папку сборки, а часть входных файлов (исходные картинки, промежуточный HTML) в репозитории отсутствовала — пересобрать приложение из репозитория было нельзя.
**Решение.** Все входы в репозитории: `data/questions.json`, `data/glossary.json`, `data/img/*.webp` (2,5 МБ), `tools/template.html`, скомпилированный `tools/tailwind/out.css`. Пути относительные. `./tools/build.sh` запускает проверки данных (T1, T2, T5) и собирает `index.html`, `sw.js`, `manifest`; при ошибке сборка падает. Node нужен только для пересборки CSS (`--css`).
**Отвергнуто.** CI/CD, npm-проект для всего, тесты интерфейса — избыточно для проекта на одного человека.
**Последствия.** Пересборка с любого компьютера с python3; риск в данных ловится до публикации.
