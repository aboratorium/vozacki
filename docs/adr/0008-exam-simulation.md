# ADR-0008: Имитация экзамена

- Статус: Принято · 17.10.2026

**Контекст.** Реальный тест: 43 вопроса, 80 баллов, порог 68. Распределение баллов по типам не опубликовано.
**Решение.** 43 вопроса пропорционально разделам; фото-ситуация = 2 балла, остальное = 1; итог приводится к шкале 80.
**Последствия.** При получении официальных весов меняются 2 константы.
