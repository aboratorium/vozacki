# ADR-0010: Стабильные ID вопросов

- Статус: Принято · 17.10.2026

**Контекст.** В v1.0 ID вопроса = порядковый номер в PDF. Прогресс привязан к ID. Если министерство добавит или уберёт вопрос, номера сдвинутся и прогресс перепутается.
**Решение.** `id` = первые 8 hex sha1 от нормализованного текста вопроса, вариантов, порядка проезда и хэша картинки. Старый номер хранится в `legacy`; при запуске приложение один раз переносит прогресс со старых ключей на новые (так же при восстановлении старой копии).
**Отвергнуто.** Ручная нумерация; UUID (не выводится из содержимого, теряется при переизвлечении).
**Последствия.** Прогресс по неизменённым вопросам переживает обновление каталога. Исправление опечатки в вопросе меняет его ID — такой вопрос считается новым (приемлемо).
