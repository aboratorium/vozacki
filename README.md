# Vozački test — тренажёр теории, кат. B (Черногория)

Офлайн-тренажёр официального каталога экзаменационных вопросов (Ministarstvo prosvjete, maj 2023):
415 вопросов с переводом на русский, подсказками и имитацией экзамена (43 вопроса, порог 68 из 80).

**Открыть:** https://aboratorium.github.io/vozacki/ → в Safari «Поделиться» → «На экран „Домой“».
После первого запуска работает без сети. Прогресс хранится на устройстве.

- `index.html`, `sw.js`, `manifest.webmanifest`, `icon-*.png` — приложение (PWA)
- `data/` — база вопросов и переводы (источник для сборки)
- `tools/` — извлечение из PDF и сборка
